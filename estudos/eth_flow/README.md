# ETH flow scalper (times & trades)

Scalper de agressão sobre o ETH futuro da B3. Código: `src/quant/strategies/eth_flow_scalper.py`.

**Status: hipótese, não edge.** Validado com apenas 1 dia de dado (PF 1,57, 43 trades), sem out-of-sample. Não usar em conta real nem simulada antes de 10-15 dias de dados.

```bash
python -m quant.strategies.eth_flow_scalper
```
